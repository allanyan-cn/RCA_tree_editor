# RCA Tree Studio

一个交互式的根本原因分析（Root Cause Analysis）树编辑器，用于构建、可视化和管理业务指标的因果关系树。

## 功能特性

- 🎨 **可视化编辑**：基于 Cytoscape 的交互式图形编辑器
- 🔀 **自动布局**：支持 ELK 自动布局算法
- 📊 **指标管理**：完整的指标定义和业务上下文管理
- 💾 **导入/导出**：支持 JSON 格式的数据持久化
- 📱 **响应式设计**：支持多种屏幕尺寸

## 快速开始

### 环境要求

- Node.js 16+
- npm 或 yarn

### 安装

```bash
npm install
```

### 开发

启动开发服务器，通常在 `http://localhost:5173`

### 构建

生成生产版本到 `dist` 目录
